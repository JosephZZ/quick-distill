% ABSTRACT
% ============================================================================
\begin{abstract}
On-policy knowledge distillation trains a student on its own generations while a teacher provides token-level soft targets via reverse KL. The standard approach computes loss uniformly across all positions, implicitly assuming all tokens contribute equally. We show this assumption is wrong and harmful: teacher signal quality decays with position, and late-position supervision causes training instability. We identify an \emph{information-quality paradox}: tokens with the highest KL divergence---seemingly the most informative---produce the \emph{worst} outcomes (53\% accuracy with 93\% KL coverage), while a simple positional prefix captures only 46\% of KL yet achieves the best results (66\%). High-KL tokens encode format/style disagreements, not reasoning quality. Based on this analysis, we propose \emph{positional distillation}: computing loss only on the first $N$ response tokens. This one-line code change yields 24$\times$ speedup, 4$\times$ memory reduction, and matches or exceeds full-sequence performance across 3 model families (Qwen, Gemma, Llama), 3 tasks (math, function calling, coding), and 2 training methods (LoRA, full fine-tuning). Multi-seed evaluation confirms 2.6$\times$ lower variance. On function calling, distilled students exceed their teachers by up to 7 percentage points. Cross-model KL profiles predict optimal position limits: $\sim$40--50\% cumulative KL coverage consistently identifies the best $N$.
\end{abstract}

\section{Method: Positional Distillation}
\label{sec:method}

The analysis in Section~\ref{sec:paradox} motivates a simple solution: restrict distillation to early positions where teacher signal is strong and independent.

\subsection{Formulation}

In standard on-policy reverse KL distillation, the student $p_\theta$ generates a response $\mathbf{x} = (x_1, \ldots, x_T)$ conditioned on a prompt, and the loss is computed against the teacher $q_\phi$:
\begin{equation}
\mathcal{L}_{\text{full}} = \mathbb{E}_{\mathbf{x} \sim p_\theta} \left[ \sum_{t=1}^{T} \KL\!\left(q_\phi(\cdot \mid \mathbf{x}_{<t}) \;\|\; p_\theta(\cdot \mid \mathbf{x}_{<t})\right) \right].
\label{eq:full_loss}
\end{equation}

\Method{} restricts the loss to the first $N$ response tokens:
\begin{equation}
\mathcal{L}_{\text{pos}} = \mathbb{E}_{\mathbf{x} \sim p_\theta} \left[ \sum_{t=1}^{N} \KL\!\left(q_\phi(\cdot \mid \mathbf{x}_{<t}) \;\|\; p_\theta(\cdot \mid \mathbf{x}_{<t})\right) \right],
\label{eq:pos_loss}
\end{equation}
where $N$ is a fixed position cutoff ($N \ll T$ in practice). If the student generates an EOS token before position $N$, loss is computed only up to EOS. The implementation requires a single line: \texttt{loss\_mask[:, N:] = 0}.

In practice, we both restrict the loss \emph{and} truncate the rollout to $N$ tokens. This couples two benefits: loss masking avoids low-quality tail positions (stability), while rollout truncation reduces generation cost (efficiency).

Since autoregressive generation dominates on-policy KD cost, truncating rollouts from $T{\sim}400$ to $N{=}100$ tokens yields a 12$\times$ wall-clock speedup (Table~\ref{tab:timing}). Positional distillation also avoids the need for a vLLM/SGLang inference server, since 100 tokens can be generated via standard HF \texttt{generate}.

\subsection{Selecting $N$ via KL Profile}
\label{sec:selecting_n}

We propose selecting $N$ at the point where cumulative KL reaches ${\sim}$40--50\% of the total. In practice, one generates ${\sim}$1{,}000 on-policy trajectories, computes per-position KL, and reads off $N$ from the cumulative curve. For front-loaded profiles (Qwen-like, KL ratio 2.81$\times$), $N{=}50$--$100$ suffices. For flat profiles (Llama-like, ratio 1.15$\times$), $N{=}150$--$200$ is needed. Section~\ref{sec:cross_family} validates this heuristic across three model families.

We find the opposite: early-token distillation reshapes the entire response. Pos-200 reduces KL by 50--58\% within the trained range (positions 0--200) and by 35--39\% in the \emph{untrained} range (positions 200--400), consistent with the strategy-then-execution structure identified in Section~\ref{sec:kl_distribution}.

\subsection{Degradation Analysis}
\label{sec:degradation}

Full-sequence distillation degrades across all three model families, with failure modes that vary by setting:

\begin{itemize}[leftmargin=*,itemsep=2pt]
    \item \textbf{Qwen math (LoRA):} avg@4 collapses from 62.35\% (step 100) to 37.75\% (step 150). Inspection reveals \bboxed{} repetition: an average of 88 \texttt{\textbackslash boxed\{\}} occurrences per response by step 100, corrupting answer extraction. The true accuracy drop is ${\sim}$4pp; the remaining 20pp is an extraction artifact of repetition.
    \item \textbf{Gemma math:} Full-seq degrades \emph{below baseline} in both LoRA (13.45\%$\to$11.70\%) and FullFT (13.45\%$\to$13.90\%), the only setting where distillation is actively harmful.
    \item \textbf{Llama function calling:} Full-seq drops from 55.3\% baseline to 32.0\% ($-$23.3pp), generating unparseable outputs.
\end{itemize}

\noindent In all cases, positional distillation eliminates the failure mode entirely. The root cause is consistent with Section~\ref{sec:analysis}: late-position loss creates degenerate training signal that accumulates over steps.

\section{Discussion}
\label{sec:discussion}

\subsection{Why Positional Distillation Works}

Three mechanisms explain the effectiveness of early-position loss restriction:

\textbf{Signal quality decay.} As established in Section~\ref{sec:analysis}, the teacher becomes less informative at later positions. Teacher entropy drops from 1.07 to 0.14; agreement rises from 58\% to 87\%. Late-position tokens contribute noise rather than reasoning signal, and restricting loss to early positions filters this noise at the source.

\textbf{Cascade effect.} In autoregressive generation, early tokens condition all subsequent tokens. Better reasoning strategy decisions (approach selection, problem framing) at positions 0--$N$ propagate through the entire response. This is not an approximation---it is a principled focus on the positions with highest leverage over the complete trajectory.

\textbf{Noise avoidance.} Late-position supervision creates degenerate attractors: repetition loops (\bboxed{} repetition in math), format collapse (unparseable outputs in function calling), and below-baseline degradation (Gemma). Truncation eliminates these failure modes entirely.

\subsection{Student Exceeds Teacher}

On function calling, positional distillation enables students to exceed teacher performance by up to 7.3pp (Qwen) and 5.9pp (Gemma). The mechanism is distributional denoising: the teacher's \emph{output} is in the wrong format (natural language for Qwen, \texttt{tool\_code} for Gemma), but the teacher's \emph{distribution} at early positions contains correct signal about function selection and argument structure. On-policy distillation extracts this distributional signal while the student generates in its own (correct JSON) format. This phenomenon requires on-policy generation---off-policy methods that copy the teacher's output tokens would inherit the wrong format.

\subsection{Limitations}

Our evaluation focuses on structured reasoning tasks (math, code, function calling) where early tokens encode a discrete strategy choice that propagates through execution. The cascade effect may be weaker for creative or open-ended tasks where later tokens introduce genuinely new content rather than executing a fixed plan. All student models are $\leq$4B parameters; scaling behavior at 7B+ is unknown. We validate only reverse KL; forward KL or other divergences may exhibit different positional signal profiles. The KL profile heuristic for selecting $N$ is validated descriptively across three families but has not been tested as a truly predictive tool on unseen model pairs. Finally, while multi-seed results (Table~\ref{tab:multiseed}) confirm robustness, we report 3 seeds on one configuration; broader significance testing would strengthen the claims.

\section{Conclusion}
\label{sec:conclusion}

We identify a fundamental asymmetry in on-policy knowledge distillation: the teacher's supervision quality decays along the response trajectory. Early tokens carry strong, independent signal about reasoning strategy; late tokens provide weak, dependent signal that is actively harmful when trained on. This motivates \methodfull{}---restricting KD loss to the first $N$ response tokens---a one-line code change that achieves 12$\times$ wall-clock speedup, 1.9$\times$ memory reduction, and eliminates training instability.

Across three model families (Qwen, Gemma, Llama), three tasks (math, function calling, coding), and two training methods (LoRA, full fine-tuning), positional distillation matches or exceeds full-sequence distillation in 5 of 6 settings while full-seq collapses in 4 of 6. Multi-seed evaluation confirms that positional distillation is both higher-performing (62.4\% vs.\ 56.8\%) and more reliable (0/3 vs.\ 2/3 collapses). The cascade effect---where early-token improvements propagate 35--39\% KL reduction into untrained positions---demonstrates that early-token distillation is not an approximation but a principled focus on the highest-quality signal.

Teaching the student how to begin is sufficient to improve the entire response.

\section{Token Classification Methodology}
\label{app:token_classification}

We classify each token into six categories based on string matching:
\begin{enumerate}
    \item \textbf{planning}: Reasoning keywords (``To'', ``Let'', ``First'', ``Step'', ``We'', ``Given'', ``Therefore'', ``Thus'', ``Since'').
    \item \textbf{structural}: Punctuation, whitespace, formatting tokens.
    \item \textbf{math\_number}: Digits (0--9).
    \item \textbf{math\_operator}: Arithmetic operators ($+$, $-$, $\times$, $/$, $=$).
    \item \textbf{math\_latex}: LaTeX delimiters (\texttt{\textbackslash(}, \texttt{\textbackslash[}).
    \item \textbf{continuation}: All others.
\end{enumerate}
